# بوت تحويل الملفات (Word/PowerPoint → PDF + صوت → نص)

## 1. الحصول على توكن البوت (تم ✅)
عندك التوكن من BotFather. لا تشاركه بأي مكان علني (GitHub عام مثلاً) — بيتحط كمتغير بيئة سري.

## 2. رفع الكود إلى GitHub
Render يحتاج الكود بمستودع GitHub عشان ينشره تلقائيًا.
1. سوّي حساب مجاني على https://github.com (لو ما عندك)
2. أنشئ مستودع جديد (Repository) — خاص أو عام، والاسم مثلاً `telegram-file-bot`
3. ارفع كل ملفات المشروع (bot.py, converters.py, transcriber.py, requirements.txt, Dockerfile, render.yaml) للمستودع

## 3. إنشاء حساب Render (بدون بطاقة ائتمان)
1. روح https://render.com وسجل حساب جديد (تقدر تسجل مباشرة بحساب GitHub)
2. من لوحة التحكم: **New +** → **Web Service**
3. اربط حساب GitHub واختر المستودع اللي رفعت فيه الكود
4. Render بيكتشف تلقائيًا وجود `Dockerfile` ويستخدمه — تأكد إن الخيار **Environment: Docker** محدد
5. اختر **Plan: Free**
6. اسم الخدمة: أي اسم تحبه (مثلاً `telegram-file-bot`)

## 4. إضافة التوكن كمتغير بيئة سري
1. داخل صفحة الخدمة على Render → تبويب **Environment**
2. أضف متغير:
   - Key: `TELEGRAM_BOT_TOKEN`
   - Value: التوكن حقك
3. (اختياري) أضف متغير `WHISPER_MODEL` بقيمة `base` (هذا هو الافتراضي أصلاً، مناسب للرام المحدودة)
4. احفظ — Render بيعيد نشر الخدمة تلقائيًا

## 5. انتظر اكتمال البناء (Build)
أول بناء بياخذ وقت أطول من العادي (5-10 دقائق) لأنه يثبت LibreOffice داخل الـ Docker image.
تابع اللوق (Logs) لين تشوف رسالة "البوت شغال بوضع Webhook على Render...".

## 6. تفعيل التشغيل المستمر (تفادي "النوم" بعد 15 دقيقة خمول)
الخطة المجانية توقف الخدمة بعد 15 دقيقة بدون طلبات. عشان تخليها صاحية قدر الإمكان:
1. روح https://cron-job.org (مجاني، بدون بطاقة)
2. سوّي حساب واضف "Cron Job" جديد
3. الرابط: رابط خدمتك على Render (تلقاه أعلى صفحة الخدمة، شكله `https://telegram-file-bot-xxxx.onrender.com`)
4. كرر الطلب كل 10 دقائق

⚠️ ملاحظة مهمة: حتى مع هذا الحل، أول رسالة توصل بعد فترة نوم قد تتأخر 30-60 ثانية (وقت "استيقاظ" الخدمة). هذا محدودية الخطة المجانية ولا يوجد حل كامل لها بدون ترقية الخطة.

## 7. التجربة
افتح تيليجرام وكلم بوتك، جرب:
- `/start`
- `حول وورد الى بي دي اف` ثم أرسل ملف .docx
- `حول الصوت الى نص` ثم أرسل رسالة صوتية

## ملاحظات مهمة عن حدود الخطة المجانية
- **الرام محدودة (~512 ميجا)**: لهذا النموذج الافتراضي لتحويل الصوت هو `base` (دقة جيدة، مو أعلى دقة ممكنة). لو واجهت أخطاء "نفاد الذاكرة" جرب تصغير الملفات الصوتية المرسلة.
- **750 ساعة تشغيل مجانية بالشهر**: تكفي لبوت واحد يشتغل باستمرار تقريبًا شهر كامل.
- **البديل الأقوى لاحقًا**: لو المشروع كبر واحتجت أداء واستقرار أفضل (خصوصًا لدقة صوت أعلى بنموذج medium/large)، الخيار الأفضل هو تشغيله على جهاز شخصي يضل شغال أو Raspberry Pi — مافيه حدود رام وما يحتاج حتى Docker أو webhook (يرجع لوضع polling العادي بحذف متغير RENDER_EXTERNAL_URL).
